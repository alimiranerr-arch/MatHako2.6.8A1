MATEMATİK MACERASI – ENTEGRASYON KURULUMU

ÖNEMLİ: Bu paket kaynak kodudur. GitHub Pages'e ZIP'i atmak Firebase Cloud Functions'ı yayımlamaz. Sunucu özellikleri için Firebase CLI ile deploy gerekir.

1) Firebase Console > Authentication > Sign-in method bölümünde Google sağlayıcısını etkinleştir.
2) Authentication > Settings > Authorized domains bölümünde alimiranerr-arch.github.io alan adının bulunduğunu doğrula.
3) Firestore Database oluştur ve Storage'ı etkinleştir.
4) Bilgisayarda Node.js LTS kur. Terminalde proje klasörüne gir:
   npm install -g firebase-tools
   firebase login
   firebase use hakomatonline261
5) Depo kökünde firebase.json, firestore.rules, storage.rules ve functions/ klasörünün bulunduğunu doğrula.
6) functions klasöründe npm install çalıştır.
7) Proje kökünde şu komutları çalıştır:
   firebase deploy --only firestore:rules,storage
   firebase deploy --only functions
8) GitHub Pages için index.html ve diğer web dosyalarını repository köküne yükle. Bu depoda web dosyaları kök dizindedir.
9) Admin olarak alimiranerr@gmail.com hesabıyla Google üzerinden giriş yap. E-postayı doğrula. İlk doğrulanmış giriş claimHakoAdmin fonksiyonunu çağırır; çıkış yapıp tekrar giriş yap.

BİLİNEN SINIRLAR / GÜVENLİK
- Cloud Functions dağıtımı Firebase Blaze (kullandıkça öde) planı ve faturalandırma hesabı gerektirebilir. Ücretleri Firebase Console'da kontrol etmeden yükseltme yapma.
- Sohbet metni, gönderilen görsel/ses/video dosyaları Firestore/Storage'a yazılır. Kullanıcı arayüzünde admin moderasyon açıklaması bulunur. Kullanıcıların göndermediği dosyalar toplanmaz.
- Konum yalnızca kullanıcı butona basıp tarayıcı izni verirse kaydedilir. Cihaz adı değil, tarayıcıdan tahmin edilen cihaz sınıfı tutulur.
- Ban kalıcıdır ve admin e-postası için engellenmiştir.
- Giriş denemesi kaydı e-posta ve zaman bilgisini içerir; parola/OTP asla kaydedilmez.
- Üyelik/market satın alımları oyun altınıyla yapılır; gerçek ödeme altyapısı yoktur.
- Sezon temaları şu an emoji/başlık katmanıdır. Özel GIF'ler kullanıcı tarafından sağlandığında eklenebilir.
- Kaybolan orijinal game.js/core.js kaynakları arşivde bulunmadığı için orijinal soru/puanlama akışı yeniden üretilemez. Bu pakette kayıp oyun mantığı yerine sahte bir kopya konulmamıştır.
- E-posta değişiminde ayda bir sınır ve tam Firebase e-posta doğrulama akışı henüz bu entegrasyon paketinde tamamlanmış değildir.
